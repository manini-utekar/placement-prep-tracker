PlacementPrep – Placement Preparation Tracker

PlacementPrep is a frontend web application designed to help students organize and track their placement preparation in one place.

The application provides separate trackers for **DSA, Development, Core CS Subjects, Aptitude, Projects, and Daily Goals**, allowing students to monitor their preparation and maintain consistency.


 Features

 DSA Tracker

* Track coding problems
* Mark problems as solved
* View solved and remaining problems
* Track difficulty-wise progress
* Links to coding problems

Development Tracker

Track progress across:

* HTML
* CSS
* JavaScript
* React
* Node.js
* Express.js
* REST APIs
* SQL
* MongoDB
* AWS
* Docker
* Deployment
 Core Subjects Tracker

Track preparation for important CS subjects:

* OOP
* DBMS
* Operating Systems
* Computer Networks

 Aptitude Tracker

Practice and track:

* Percentages
* Profit & Loss
* Time & Work
* Number Series
* Blood Relations
* Seating Arrangement
* Vocabulary
* Reading Comprehension
* Grammar

 Purpose

Placement preparation often involves managing multiple areas such as coding, development, aptitude, core CS subjects and projects.

PlacementPrep brings these areas together into a single dashboard so that students can:

* Organize their preparation
* Track completed topics
* Maintain consistency
* Monitor their progress
* Plan their daily preparation
